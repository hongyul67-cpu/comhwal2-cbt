# 컴활 2급 필기 CBT 모의고사

실제 시험처럼 풀고 **과락·합격까지 자동 판정**하는 CBT.

- 2과목(컴퓨터 일반 / 스프레드시트 일반) · **40문항 40분**
- 합격 기준: 한 과목이라도 **40점 미만이면 과락**, 과락 없이 **평균 60점 이상**이면 합격
- 문제 팔레트(안 푼 문제 / 다시 볼 문제 표시), 오답노트, 회차를 넘어 쌓이는 누적 오답

## 문제 은행
| 출처 | 파일 | 내용 |
|---|---|---|
| 실제 기출 | `data/best-1~4.js` | 자주 출제되는 기출문제 **120선** (40개 주제) |
| 실제 기출 | `data/r2023-1~3.js`, `r2022-1~2.js` | 회차별 실전 기출 **200문항** (5회차 × 40문항) |
| 개념 문제 | comhwal2 저장소 | `data/comp.js`, `data/excel.js` 를 원격 로드 |

개념 문제는 배포된 `hongyul67-cpu.github.io/comhwal2/` 에서 불러오며,
불러오지 못하면 `../comhwal2/data/*.js` 로 자동 재시도합니다(로컬 개발용).

전체 **실제 기출 320문항**. 랜덤 모의고사도 이 기출 풀에서 먼저 뽑고 모자란 만큼만 개념 문제로 채웁니다.
