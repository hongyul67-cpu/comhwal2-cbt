# 컴활 2급 필기 CBT 모의고사

실제 시험처럼 풀고 **과락·합격까지 자동 판정**하는 CBT.

- 2과목(컴퓨터 일반 / 스프레드시트 일반) · **40문항 40분**
- 합격 기준: 한 과목이라도 **40점 미만이면 과락**, 과락 없이 **평균 60점 이상**이면 합격
- 문제 팔레트(안 푼 문제 / 다시 볼 문제 표시), 오답노트, 회차를 넘어 쌓이는 누적 오답

## 문제 은행
| 출처 | 파일 | 내용 | 공개 여부 |
|---|---|---|---|
| 실제 기출 | `past.enc` | 자주 출제되는 기출문제 **120선** + 2022~2023 상시 기출 **200문항**(5회) + 2016~2024 기출 **581문항**(15회, 옛 버전 문항 19개 제외) = **901문항** | 🔒 AES-GCM 암호화 (코드 입력 시에만 열림) |
| 개념 문제 | comhwal2 저장소 | `data/comp.js`, `data/excel.js` 를 원격 로드 | 공개 (코드 없이 바로 풀림) |

### 🔒 기출이 잠겨 있는 이유

기출 회차와 120선은 시중 판매 **기출공략집을 옮긴 것**이라 그대로 공개하면 저작권 침해가 됩니다.
정적 호스팅에서는 화면에 비밀번호 칸만 두어도 보호가 되지 않으므로(`data/r2023-1.js` 주소를 직접 치면
그대로 받아집니다) **파일 자체를 AES-GCM 으로 암호화**해 `past.enc` 하나로 올립니다.

- 암호는 두 종류 — **교사용**(문구형·만료 없음, 열면 그 주 학생 코드가 화면에 나옴) / **학생용**(8자리 숫자, 그 주 7일)
- 코드는 다른 잠긴 도구(신재생·공업일반·반도체 등)와 **같은 8자리**입니다 (`_weekly/secret.json` 공용)
- 한 번 연 기기는 다음부터 바로 열립니다
- **개념 문제 모의고사는 잠기지 않습니다** — 코드가 없어도 랜덤·과목별 모의고사는 그대로 풀 수 있습니다

### 다시 굽기

평문 `data/best-*.js` · `data/r20*.js` 는 `.gitignore` 라 **이 PC에만** 있습니다.
문항을 고쳤으면 그 파일들이 있는 PC에서:

```
python build_lock.py
```

개념 문제는 배포된 `hongyul67-cpu.github.io/comhwal2/` 에서 불러오며,
불러오지 못하면 `../comhwal2/data/*.js` 로 자동 재시도합니다(로컬 개발용).

전체 **실제 기출 901문항**(회차 20개). 랜덤 모의고사도 이 기출 풀에서 먼저 뽑고 모자란 만큼만 개념 문제로 채웁니다.
